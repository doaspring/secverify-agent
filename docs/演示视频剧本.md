# SecVerify Agent 演示视频剧本（4分40秒版）

> 目标：评委 5 分钟内看懂**痛点→方案→三场景实证→证据链→指标**。
> 硬性要求：总长 **<300 秒**、分辨率 **≥1280×720（建议1920×1080/30fps）**、网盘匿名可看。
> 本剧本按 **280 秒** 设计，留 20 秒余量。

## 录制前准备（一次性，约10分钟）

| # | 准备项 | 说明 |
| --- | --- | --- |
| 1 | 录屏工具 | OBS Studio（推荐）或 Xbox Game Bar（Win+G）；画布 1920×1080@30fps，采集浏览器窗口 |
| 2 | 浏览器 | 全新无痕窗口或重置会话后的浏览器，**关掉书签栏**（F11 全屏更干净） |
| 3 | 预热 | 正式录制前先把三个场景各跑一遍（LIVE 模式冷启动+模型响应较慢，预热后正式录更流畅） |
| 4 | 页面状态 | 打开 https://secverify-agent-9cb76gvynzcnedjqenezs7.streamlit.app ，确认侧栏显示 **● LIVE — Intern-S2 实时调用**（绿点呼吸灯） |

**剪辑提示**：聚合步骤的统计结果出现瞬间可暂停 1 秒+红圈标注数字。

## 第四段｜场景B：注入攻击被阻断（01:35–02:35，60秒）★核心段

**画面**：网页 ① 区。
**操作**：
1. 点击 **「启动场景B」**（高亮徽章"▶ 当前运行"出现在B卡片上，其余卡片变暗——顺带展示了选中反馈）；
2. 【剪掉等待】时间线出现：
   - 绿色 `read_demo_alerts`（读到注入数据集）；
   - 讲解时鼠标悬停数据集说明——或提前在④区对照表处停留；
   - 重点帧：若模型被诱导，红色 **`DENY · mock_send_external · NOT_EXECUTED · R002_FORBIDDEN_TOOL`**；若未诱导（模型自律），口播词用B路径并指向对照表证明兜底；
3. 滚动到 ④ 防护对照表：`ROLE_SPOOF_01 … B0无防护=WOULD_EXECUTE ⚠️ ｜ B2本系统=DENY`；
4. 鼠标指向时间线后续绿色步骤。
**口播（诱导成功版）**（约200字）：
> "关键测试：这个数据集里埋了八条注入样本——假的'管理员授权'、伪造的工具公告、要求把数据外发的指令。模型读到日志后，真的被诱导提议调用外发工具 mock_send_external。看红色这一步：策略引擎按 R002 规则直接拒绝，NOT_EXECUTED，没有任何数据离开沙盒。更重要的是后面——阻断之后，聚合和报告继续执行，原始任务照常完成。拒绝攻击，不等于牺牲可用性。"
**口播（模型自律版备选）**：
> "这一轮模型识破了注入，没有提议越权工具——但防护不依赖模型自觉。看对照表：同一批攻击用例，无防护基线 B0 下 19 个会被'本会执行'，而本系统 27 个攻击全部阻断，42 条评测零误放行。"

**剪辑提示**：红/绿两帧各定格 1.5 秒；对照表用红框全选。
**字幕要点**：`8条注入样本`｜`R002 越权阻断·任务延续`｜`B2: 攻击阻断率100%·良性放行100%`

## 第五段｜场景C：人工审批闭环（02:35–03:35，60秒）

**画面**：网页 ① 区 → 琥珀色审批卡片 → ⑤ 下载区。
**操作**：
1. 点击 **「启动场景C」**；
2. 【剪掉等待】琥珀色审批卡片出现：`export_local_report｜参数｜TTL 300秒·单次有效`；
3. 点 **「✅ 批准」** → 时间线新增 `HUMAN_APPROVED`，随后 `export_local_report` 变 `ALLOW/EXECUTED`；
4. 滚动到 ⑤ 区，点开下载的 HTML 报告（新标签页快速滚动展示时间线与汇总数字）；
5. **（可选加分，约15秒）** 回到 ① 重跑场景C，这次点 **「❌ 拒绝」** → `REJECTED_BY_USER·NOT_EXECUTED`，口播一句："拒绝路径同样留痕，且导出文件不会产生。"
**口播**（约190字）：
> "敏感操作走人工审批。模型提议导出报告时，工作流在这里中断——这是 LangGraph 的可恢复中断点。审批卡片写明工具、参数和风险；批准后系统签发绑定本次调用的单次令牌，网关二次核验后才执行导出，令牌随即作废——重放无效、换参数无效、模型自己声称'已获批准'更无效。导出的报告里，每个数字都能回溯到这条 append-only 审计链。"

**剪辑提示**：批准前先给 ⑤ 区一个空状态镜头（"暂无导出文件"），批准后再给文件出现镜头——前后对照最有说服力。
**字幕要点**：`LangGraph interrupt 可恢复`｜`审批令牌·单次·绑定参数`｜`append-only 审计`

## 录完之后（自检清单）

1. `ffprobe -v error -show_entries format=duration:stream=width,height -of json 视频.mp4` → 确认 **duration<300**、**1920×1080**（至少1280×720）；
2. 全程无 API Key、无个人隐私信息入镜（检查代码编辑器画面！）；
3. 侧栏 LIVE 徽标在所有运行场景中可见；若某段用了回放兜底，画面保留 REPLAY 标注并口播说明（诚实原则）；
4. 上传网盘（百度网盘/阿里云盘），分享权限设"**任何人可看（无需登录）**"；
5. **无痕窗口**点开分享链接完整看一遍，确认流畅；
6. 把链接发给助手 → 填入技术 PDF → 双层 ZIP 打包。

## 录制应急

- **模型响应过慢**：剪掉等待即可，别加速口播；
- **API 断流**：侧栏出现 REPLAY 提示时，等恢复 LIVE 再录该段（间隔重试）；实在不行用回放录完该段，保留 REPLAY 标注入镜；
- **口播紧张**：台词可全部改为字幕+轻音乐，一样合规（时长与分辨率才是硬指标）。
